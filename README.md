# palmstead
Back to when devices were tools.

An Android launcher inspired by PalmOS Garnet.

- **Garnet style**: low-resolution fonts and large icons on an emulated 320×480 screen
  (switchable to the display's full resolution in Settings), time and battery in the title bar,
  a category filter at the upper right, a thin scroll-position indicator on the right, and a
  configurable bottom row of buttons (most-used apps by default).
- **All apps**: via an "All Apps" bottom-row button, a swipe-up on the bottom row, an "All Apps"
  shortcut in the Home list, or the "All" category — each configurable in Settings.
- **Modern style**: normal fonts, icons and UI elements, limited to a usable physical size using the screen PPI.

Open Settings by long-pressing the title bar or via the category menu. Build with `gradle assembleDebug`.
